# fst-time-series-simulations: neutral Fst expectations for historical-modern time series

Split out of grenenet-phase2 (commit 5cad5b7, 2026-11-02). Simulates the
distribution of Fst between "historical" and "modern" sample sets under
 neutrality, via SLiM (structural variants in a finite genome) -> msprime
(recapitation) -> bcftools/plink -> GCTA. The notebook in `resources/`
compares the SLiM Nei-1973 Fst against the GCTA Weir-1996 Fst and derives
genome-wide quantile baselines.

## Entry points

- **Snakemake pipeline**: `workflow/Snakefile` is the main entry point.
  - `all_fst_sims` — msprime/GCTA Fst workflow (`msprime_results/{ID}.txt`,
    `gcta_results/{ID}.fst`).

Run from inside `workflow/`:

```bash
cd workflow
snakemake --profile profiles/default all_fst_sims --dry-run
snakemake --profile profiles/default all_fst_sims
```

Profiles:

- `profiles/default` — Slurm on Savio (account co_moilab).
- `profiles/msu` — MSU Slurm profile.
- `profiles/local` — local execution.

## Parameter generation

`resources/sim_parameters.R` generates `config/fst_params.tsv` (run it from
`resources/` before the first dry-run). `config/sampling_times.tsv` is
generated by the `## historical vs modern pairings` chunk of
`resources/fst_notebook.Rmd` from `data/comb_hist+1001g.prs_geo+gen.csv`.

`data/` is gitignored: copy
`grenenet-phase2/data/comb_hist+1001g.prs_geo+gen.csv` into `data/` here
before running the notebook.

## Gotchas

- **Absolute paths**: generated config tables carry no absolute paths, but
  the analysis notebook uses absolute `/global/scratch/users/milesroberts/fst-time-series-simulations/...`
  paths — update them for a new machine.
- **Conda env pinning**: `workflow/envs/*.yaml` files carry `prefix:` lines
  from the original Savio conda cache; Snakemake rebuilds envs fresh here.
  The `msprime` env includes SLiM 5.1, tskit, and pyslim — it backs both the
  SLiM and msprime steps.
- **Aggregation rules** (`grep_msprime`, `grep_gcta`) write
  `fst_results.txt` / `gcta_fst.txt` at the workflow root; they are not in
  the default target, run them by name.
