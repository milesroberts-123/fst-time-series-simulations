# fst-time-series-simulations — agent notes

Repository for neutral Fst-expectation simulations between historical and
modern sample sets. Split from grenenet-phase2 (SLiM -> msprime -> GCTA
workflow). Primary languages: Snakemake, Python (msprime), SLiM, R.

## Entry points

- **Snakemake pipeline**: `workflow/Snakefile` is the main entry point.
  - `all_fst_sims` — SLiM structural-variant simulation (`slim_fst_results/{ID}.trees`),
    recapitation in msprime (`scripts/burnin.py`), VCF merging (`bcftools`),
    and Fst estimation (`msprime_results/{ID}.txt` via msprime's Weir-Cockerham
    style output, `gcta_results/{ID}.fst` via GCTA).
- **Parameter generation**: `resources/sim_parameters.R` regenerates
  `config/fst_params.tsv`. `config/sampling_times.tsv` is generated by the
  pairings chunk in `resources/fst_notebook.Rmd`.

## Running the pipeline

Run from inside `workflow/`:

```bash
cd workflow
snakemake --profile profiles/default all_fst_sims --dry-run
snakemake --profile profiles/default all_fst_sims
```

Profiles: `profiles/default` (Savio Slurm, account `co_moilab`),
`profiles/msu` (MSU Slurm), `profiles/local` (local execution).

## R workflow conventions

- The only R analysis is `resources/fst_notebook.Rmd`; it writes outputs to
  `results/by-date/<YYYY-MM-DD>/` using `today <- Sys.Date()`.
- `data/` holds the historical/modern pairing table; it is gitignored — copy
  `grenenet-phase2/data/comb_hist+1001g.prs_geo+gen.csv` here.

## Important gotchas

- **`.gitignore` is aggressive**: ignores `*.tsv`, `*.csv`, `*.txt`, `*.pdf`,
  `*.html`, `data/`, `results/`, `.snakemake/`. Generated params and outputs
  stay out of git.
- **Env yaml `prefix:` lines** point at the conda cache of the machine the
  envs were built on; Snakemake builds fresh envs elsewhere.
- **No memory resources in `profiles/default`**: Savio restricts memory
  requests on the HTC partitions; memory belongs in `profiles/msu` or local.
- **Absolute paths in `fst_notebook.Rmd`** point to
  `/global/scratch/users/milesroberts/fst-time-series-simulations/...` and
  must be updated for a new machine.
